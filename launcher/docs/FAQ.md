# 常见问题

没有找到答案时，请到[项目 QQ 群](https://qm.qq.com/q/eeUrxIltug)交流，或在 [GitHub Issues](https://github.com/YomotsuHisami/eagler-touhou/issues)报告问题。

## 游戏打不开、黑屏或输入没有反应

先更新浏览器并确认 WebGL 2.0 可用。旧设备或浏览器的设置步骤见[设备与浏览器兼容指南](compatibility.html)。若仍有问题，刷新页面，检查游戏资源是否已安装，再重试启动。

## 怎样安装游戏资源？

联网打开游戏卡片，按页面提示下载资源；也可以在“导入游戏资源”中导入你合法持有的本地游戏包。下载完成后，启动器会从浏览器本地存储读取该游戏资源。

## 断网时可以玩吗？

可以在安全站点上下好启动器、所选游戏的 Runtime 和游戏资源后离线启动该游戏；其他游戏尚未准备的资源不会因安装启动器而自动下载。联机和资源下载需要网络。

## 存档和 Replay 保存在哪里？

存档和 Replay 保存在当前浏览器的本地数据中，各作品分别管理。在游戏设置的文件操作中可以导入或导出原版存档与 Replay。更换浏览器、清除站点数据或更换设备前，请先导出需要保留的文件。

## 游戏怎么操作？

默认键位是方向键移动和选择、Z 射击和确认、X 使用 Bomb 和取消、按住 Shift 低速移动、Esc 暂停或返回、Ctrl 快进对话。启动游戏后可打开帮助查看操作与移动教程；手柄按键和触控布局可在设置中调整。

## 怎样开始联机？

在游戏列表中选择带“联机”标记的作品，进入房间后邀请队友。联机需要网络连接和站点的联机服务；如果大厅不可用，请稍后重试或联系该站点管理员。联机规则可在游戏页面的“联机玩法介绍”中查看。
