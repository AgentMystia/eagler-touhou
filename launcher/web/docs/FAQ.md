# 常见问题

## 加载失败、黑屏、卡顿或触控异常怎么办？

先确认问题发生在打开启动器、安装资源还是进入游戏。查看页面错误提示；检查剩余存储空间，并尝试关闭可能接管下载或页面操作的扩展。不要先清空站点数据，那里可能保存着未备份的存档和 Replay。

请使用仍受维护的浏览器版本。内置网页、浏览器外壳、系统 WebView 和真实浏览器的能力可能不同；设备是否可用以页面检测和实际启动为准，不能只按品牌判断。旧浏览器或 WebGL 检测失败可查看[设备与浏览器兼容指南](compatibility.html)。

反馈时请附上作品和模式、浏览器及系统版本、操作步骤、出现问题的阶段，以及可公开的错误信息。可通过 [GitHub Issues](https://github.com/YomotsuHisami/eagler-touhou/issues) 或 [QQ群](https://qm.qq.com/q/eeUrxIltug) 联系项目；不要公开私有配置、个人存档或完整原版资源。

## 怎样查看操作说明和游戏规则？

进入游戏后使用帮助入口查看键盘和触屏操作。联机协作的规则与单人原作不同，见联机玩法介绍。

原版附带说明可参考[东方 Project 附带文档](https://omake.thwiki.cc/)，攻略可查阅 [THBWiki](https://thbwiki.cc/)。这些内容与网页移植的具体实现可能存在差异。

## 存档保存在哪里？可以中途退出后继续吗？

成绩、解锁和设置等文件保存在当前浏览器、当前站点的存储中。不同作品、普通模式和多人模式的写入规则可能不同；以对应文件管理和游戏行为为准。

导出功能保存的是游戏文件，不是任意时刻的内存快照。它不承诺关闭浏览器后能恢复一局中途状态。Replay 也不等于中途存档。

请定期导出需要保留的文件。不同作品的存档不能混用；切换浏览器或地址前先备份。

## 已经打开过，为什么离线时仍不能玩？

启动器离线准备和游戏资源安装是两个步骤。首次访问未完成安装、只缓存了启动器、资源被清理或换了站点地址，都可能需要重新联网。多人联机及尚未下载的资源仍然需要网络。

离线测试应在在线安装结束后进行，关闭并重新打开页面验证。不要把一次成功访问当作所有游戏都已安装。

## 下载不了资源怎么办？

查看错误对应的资源，检查网络和剩余空间，重试或换用可用网络。代理、下载插件及网络过滤可能影响请求，是否需要调整应依据实际错误。

站点提供外部下载链接时，可以取得兼容的导入包并主动导入。不要修改包内字节、把不同版本文件混装，或把网页入口 ZIP 当作游戏资源包。

## 为什么联机连接不上或容易停顿？

联机依赖站点配置、房间服务、双方网络及具体 Runtime。系统使用 WebRTC 与 WebSocket 中继等链路，不能通过 NAT 类型编号相加推断可用性。

先确认双方进入同一作品和兼容模式，查看房间连接提示与实际传输状态。服务未配置、WSS 不可达、丢包、网络切换或设备跟不上逻辑步，都需要分别排查。中继可改善可达性，但不会消除延迟和性能差异。

观战、回放和人数限制取决于所选游戏及 Runtime；按页面可用操作使用。不要从某作支持观战推断所有作品相同。

## 其他作品和其他平台何时支持？

当前可选内容以站点实际发布为准。工程进度区分源码实现、构建和浏览器验收，不承诺尚未确定的作品、平台外壳或上线时间。
