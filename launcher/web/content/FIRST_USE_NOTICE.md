# 首次使用须知

## 资源准备完成后再开始

首次使用会下载启动器和所选游戏需要的资源。请等待安装完成；下载中断时按页面提示重试，也可以导入与当前版本兼容的游戏包。

## 离线使用需要提前安装

启动器完成离线准备、游戏资源完成安装后，可在没有网络时尝试启动已安装游戏。浏览器清理站点数据、隐私模式和存储回收可能影响离线资源；多人联机仍需要网络。

## 及时备份存档与 Replay

浏览器中的数据属于当前设备、浏览器和站点地址。更换浏览器、清理数据或迁移地址前，请先导出需要保留的存档与 Replay。不同作品的存档不能混用。

## 操作与问题反馈

游戏内的帮助入口说明键盘和触屏操作。遇到黑屏、加载失败、断触或存档问题，请查看常见问题，记录作品、浏览器、复现步骤和错误提示后再反馈。
