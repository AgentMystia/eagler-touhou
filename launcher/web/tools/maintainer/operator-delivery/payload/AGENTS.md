# 运营操作约定

这是生成的交付包。先阅读 `README.md`、`services/README.md`、能力 profile 和验证报告，再操作主机。

只对已明确授权的目标进行部署。域名、目录、证书、Relay、TURN 和迁移阶段必须来自实际配置，不自行猜测。先校验交付，保留原件和上一可用代次。

生产配置放在私有服务目录，限制密钥访问。使用 nginx 时先运行配置检查再重载。迁移窗口保留 HTTP `/migrate.html`，最终 HTTPS 阶段先退役迁移能力再启用相应 HSTS。

报告区分文件、HTTP、服务连接、浏览器安装和游戏验证；不能用进程存活或响应码代替后两者。
